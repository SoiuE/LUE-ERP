# 图片功能阶段 3 验收记录

日期：2026-10-17

## 实现范围

- PC SKU 列表与商品详情、仓库货品列表和选择器、销售 SKU 组成货品选择、发货单详情与拣货任务、采购确认与收货、库位库存与异常中心增加对应 SKU 或仓库货品的标准参考图。
- 手机工作台增加 SKU 查询；手机发货单、拣货任务、采购确认与收货、货品任务增加标准参考图。拣货任务同屏保留编码、名称、规格、来源库位及数量。
- 新增批量只读接口 `GET /api/images/references?objectType=SKU|WAREHOUSE_GOODS&ids=...`，每次最多 100 个对象，按主图、顺序、资产 ID 选择活动图片。返回资产标识、来源类型和外链 URL，不返回图片二进制。上传图片缩略图继续使用阶段 1 的受控接口；外链沿用阶段 2 的浏览器懒加载和失败占位。
- 图片查询失败只显示无图状态，不参与扫码、数量、收货、拣货等提交。读取权限由 API 按对象类型及现有页面权限执行；图片库的维护权限没有放宽。现场照片继续使用业务附件链路，与标准图库分开。

## 已知限制

- 阶段 1 没有外链缩略图生成或代理。上传资产的列表图片调用缩略图接口；外链资产在进入视口后由浏览器直接加载原外链，可能下载原图。批量业务 API 不抓取外链，也不会为每一行同步检查 URL。
- 当前盘点作业针对包材，不存在仓库货品盘点详情；未把货品标准图加到包材盘点页面。异常中心对已关联 SKU 的异常显示其参考图，未匹配时在 SKU 选择项显示候选图。
- 未使用隔离数据库或对象存储执行阶段 3 的集成验收，部署验收仍需用有图、无图、坏外链及多图样本检查页面和权限。
