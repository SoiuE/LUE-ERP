# LUE ERP 图片功能 AI 分阶段开发指令

版本：v1.0
日期：2026-10-17
需求基线：`docs/image-function-requirements.md`
适用项目：当前 LUE ERP 工作区

## 使用说明

- 按阶段顺序逐条执行，一次只执行一个阶段。
- 阶段 0 只读盘点，先审阅其结果，再进入实现阶段。
- 每阶段结束后审查代码差异、迁移、权限、接口、页面和验证结果；该阶段未通过前不要叠加后续阶段。
- 本文每条阶段提示均包含可独立执行的约束；复制阶段内容即可，不必再拼接额外总提示词。
- 当前数据库中的业务数据均为测试数据，不要求保留，也不需要业务数据迁移或历史数据映射工具。仍须核实数据库连接目标；不得把开发指令解释为可以清空任意数据库。数据库结构使用新的 Flyway 向前迁移，不修改既有迁移文件。
- 当前任务只实现图片功能，不顺手重构无关模块或改动库存、采购、履约、利润业务规则。

## 阶段 1：图片资产、文件存储与后端基础-已发送

~~~text
先阅读 `docs/image-function-requirements.md`、本指令文件和阶段 0 盘点结果image-function-stage0-inventory.md，并检查相关现有代码。本次只实现图片资产基础：数据库模型、存储抽象、上传/外链登记/读取 API、权限和审计；不改业务流程页面、不实现图像相似搜索。

数据前提：当前数据库业务数据是测试数据，不要求保留，不需要历史业务数据迁移或映射。但必须核实实际连接配置，绝不清理未知数据库。新增数据库结构使用新的 Flyway 迁移，禁止编辑已存在迁移文件。

实现范围：
- 建立支持 UPLOAD、EXTERNAL_URL、ARCHIVED_URL 来源的图片资产与关联模型；支持 SKU、WAREHOUSE_GOODS、多图、主图、排序、用途类型、标签、备注、状态和创建人/时间。
- 文件内容存于文件服务，优先复用部署中的 MinIO；对存储客户端进行配置化，不把凭据写入代码；数据库不存二进制内容或临时签名 URL。
- 复用现有登录态、统一 API 响应、错误处理和操作日志。查看、上传、维护、关联/解除关联、主图修改和停用均由服务端校验权限。
- 实现上传、创建外部 URL 资产、查询资产、关联/解除关联、设置主图/排序、停用以及受控读取所需 API。接口命名应先检查现有规范，避免重复端点。
- URL 只接受 HTTP/HTTPS。浏览器直连外链不需要服务端抓取；本阶段若实现任何服务端抓取，必须按 SSRF 规则实施目标 IP、重定向、超时、大小、MIME 和文件签名校验。不得构造任意 URL 图片代理。
- 对上传文件校验内容类型、文件签名、大小和像素尺寸；随机化对象名，禁止路径穿越。错误不得泄露本地路径、存储密钥或内部地址。
- 删除采取软停用或安全回收机制；检查共享关联，解除关联不能误删其他对象仍使用的文件。
- 不把手机现场附件自动复制进图片资产表；只实现必要的共享存储抽象，现场附件关联逻辑不改变。
- 通过适当的权限代码和菜单配置让后续阶段可接入；遵循项目现有默认授权约定。

范围控制：不改 SKU/货品表单，不改拣货/采购/库存行为，不实现缩略图任务或向量搜索，不做无关格式化和重构。

开始修改前先简要说明将改哪些文件、迁移结构和 MinIO 配置方式。完成后检查 diff，运行与本阶段相关的后端构建/自动化验证并报告真实结果；若环境或依赖阻塞，说明未验证项，不得声称通过。阶段验收：资产和关联可经授权 API 操作；外链、上传文件元数据持久化正确；文件读取受控；越权请求被拒绝；迁移为新增迁移且现有文件未修改。完成后停止。
~~~

## 阶段 2：图片库、SKU/货品维护和链接兼容-已发送

~~~text
先阅读图片功能需求、阶段 0 盘点和阶段 1 验收结果。本次实现 PC 图片库、SKU/仓库货品多图维护、图片预览和 `image_url` 兼容；不改仓库拣货/采购流程，不实现以图搜图。

实现范围：
- 在现有 Vue 3 + TypeScript/Element Plus 架构内新增图片库入口、路由和页面，权限接入现有路由/菜单模式。
- 图片库支持分页、缩略图网格、按 SKU/仓库货品、对象类型、图片用途、标签和状态筛选；提供上传、添加外链、预览、维护备注/标签/类型、关联对象、主图与顺序、解除关联和停用。
- 在 SKU 详情和仓库货品档案/详情中提供多图维护入口。不得把单一 URL 文本框当作最终的多图功能。
- 现有 SKU `image_url` 及导入字段继续可用：导入 URL 后可转换/关联为 EXTERNAL_URL 资产，且重复导入按现有幂等/更新规则处理；先审计当前导入写入行为，避免更改其他 SKU 字段语义。
- 外链图片采用懒加载和失败占位状态，失败时仍能编辑或替换 URL/上传图片。防止坏链接造成页面报错。
- 使用 Element Plus 现有设计风格。图片查看器支持关闭和大图预览；缩略图不加载原图。
- PC 页面仍展示编码、名称、规格等文本，图片只是辅助识别。
- 现场操作附件不混进商品图库。

质量要求：调用阶段 1 API，不重复实现文件存储、授权或响应解析。检查 Vue 类型、空/加载/错误状态、移动视口基本适配。变更仅限必要前端和相关后端兼容逻辑。

完成后检查 diff 和相关前后端构建/自动化验证，报告命令与真实结果。验收：SKU 和货品可维护多图；平台 image_url 导入图可显示；失败外链有占位和修复入口；按条件筛选分页；权限由 API 执行；无无关业务回归。完成后停止。
~~~

限制修改范围为本阶段上述页面及必要的读 API/DTO。先列出计划修改文件和数据请求变化，再实施。完成后验证相关前后端构建/自动化检查和断点状态（无图、坏外链、多图、手机小屏），如未实际运行则如实标注。验收：关键页面能看到正确对象的主图，现场照片与标准图不混，图像服务不可用不会阻止主要业务操作。完成后停止。

## 阶段 4：外链归档、缩略图与索引准备

~~~text
先阅读图片需求和阶段 1-3 交付结果。本次实现用户触发的外链图片本地归档、缩略图和以图搜索引状态准备，不接入真实向量检索。

实现要求：
- 后端异步或有界执行外链下载，不在业务列表/请求线程中无限等待；限制为 HTTPS/HTTP、禁止私网/环回/链路本地/云元数据 IP、校验 DNS 解析结果、限制重定向、连接/读取时限、响应大小、MIME 和文件签名，防 SSRF 与资源耗尽。
- 归档成功创建本地对象并保留原 URL；失败保留外链状态和可读错误，不覆盖原资产。
- 生成缩略图并能回退到原图查看；生成失败不损坏原图。
- 控制重复归档/重复提交；记录处理状态、尝试时间和重试入口。
- 维护向量索引准备状态（未索引、待索引、已索引、失败等），但本阶段不引入模型、向量库或改变生产/测试库配置。
- 默认不索引现场操作附件。

仅在阶段 0 证明项目没有合适现成方案时才引入新依赖；说明体积、维护和部署影响。相关后台任务如需 Redis/任务队列，应先检查现有设施并选择最小实现。

完成后检查安全边界、错误重试、前后端构建/自动化验证和 diff。验收：安全归档成功/失败都不丢原链接；缩略图错误不影响原图；重复请求不会产生失控副本；全过程可观察。完成后停止。
~~~

## 阶段 5：以图搜商品

~~~text
先阅读图片功能需求与阶段 0-4 交付结果。本次实现真正的相似图片检索，支持内部销售 SKU 和仓库货品；不得影响现有业务单据和库存。

开始编码前先基于实际部署能力确定模型、服务和索引方案：按需求建议独立 Python FastAPI 图片搜索服务和 CLIP 类图像特征；向量索引可选择 Qdrant、Milvus 或经验证的轻量方案。给出比较、资源/模型下载需求、部署配置、索引重建和备份方案，再选最小可行方案。不要让浏览器直接访问搜索服务或向量库。

实现范围：
- 搜索页支持上传/拍摄查询图；验证大小、格式和像素，临时文件有清理策略，不默认进入商品图库。
- 后端鉴权并调用搜索服务；搜索服务返回图片资产/对象候选，后端聚合商品详情和可用库存。
- 结果 Top 10 按相似度排序，同一对象多图合并，显示匹配度、对象类型、SKU/货品编码、名称、规格、图片及库存；允许跳转详情和确认候选。
- 默认索引商品主图和商品实物图；包装图可选；现场操作照片排除。
- 图片资产新增、替换、停用时更新索引状态；提供失败重试、积压可见性和索引重建能力。
- 搜索服务不可用时提供清楚错误和手工 SKU/货品搜索回退，不影响采购、收货、库存、拣货和交接。
- 搜索结果不得自动修改店铺映射、货品组成、库存或任何履约记录。

完成后验证离线/不可用降级、空索引、低相似度、重复对象合并和 Top 10 上限；执行相关构建/自动化验证并报告真实结果。验收：查询图可返回有效候选并能跳转详情，索引状态可追踪，确认前无业务数据写入。完成后停止。
~~~

## 每阶段统一交付规则

- 开始前简述阶段目标、现状和拟修改文件；需求明确后直接推进，不重复询问已经由本文件确定的选择。
- 遇到需求与当前代码冲突时，以 `docs/image-function-requirements.md` 的图片需求为准，同时保留无关既有业务行为；先说明实际冲突和最小解决方式。
- 不修改阶段范围外文件；避免整页重写和大规模格式化。
- 不修改已执行的 Flyway 文件；新迁移命名遵循现有版本顺序和格式。
- 所有外链抓取必须执行 SSRF 与资源限制；不能以“测试数据”作为放宽网络安全的理由。
- 不在前端直接暴露存储密钥、向量库或服务端内部地址。
- 图片故障不能阻断核心业务；图片候选不能自动更改库存或业务关联。
- 结束时列出修改文件、关键实现、权限/迁移影响、验证命令和结果、未完成项。任何验证未执行或失败都明确说明。
