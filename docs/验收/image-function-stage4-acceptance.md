# 图片功能阶段 4 验收记录

日期：2026-10-17

## 交付范围

- 图片库中的活动外链资产可由有图片维护权限的用户触发归档或失败重试。`POST /api/images/{id}/archive` 只写入持久任务状态并返回，不在请求线程下载外链。
- V23 迁移为资产增加归档、缩略图和索引准备状态、错误、尝试次数及处理时间。索引状态支持 `NOT_INDEXED`、`PENDING`、`INDEXED`、`FAILED`；本阶段没有模型、向量库或真实索引执行器。
- 归档任务使用数据库状态持久排队，Spring 有界线程池默认 2 个工作线程、20 个排队项。调度器每 3 秒领取待处理任务，并将中断超过 5 分钟的任务重新排队。条件更新保证同一资产只有一个工作线程取得处理权。
- 成功归档时，同一资产改为 `ARCHIVED_URL`，对象存储保存本地原图，原始外链移入 `source_url` 保留。失败时资产保持 `EXTERNAL_URL`，保存可读错误和完成时间。
- 上传和归档图片会尝试生成 320 像素 JPEG 缩略图并单独保存。缩略图失败只记录 `FAILED`，不撤销或删除原图；缩略图读取失败会回退为从原图即时生成，原图内容端点保持可用。
- 图片库显示来源、归档状态、尝试次数、最近尝试/完成时间、归档错误、缩略图状态和索引状态，并提供归档及失败重试入口。
- `warehouse_operation_attachments` 及其上传、关联和读取流程未修改，不进入上述商品图片索引状态。

## 安全边界

- 只接受无用户凭据、无 URL 片段的 HTTP/HTTPS 地址；禁用系统代理、自动重定向、连接重试和内容压缩协商。
- 每个初始地址及每次重定向都重新解析 DNS。实际 HTTP 客户端使用同一安全 DNS 实现，只返回已校验地址，拒绝任意地址、环回、站点本地、链路本地、组播、IPv6 ULA、IPv4 兼容地址、CGNAT `100.64.0.0/10`、基准测试网段和云元数据常用链路本地地址。
- 默认连接超时 3 秒、读取超时 7 秒、单次调用总超时 12 秒、最多 3 次重定向、最大响应 10 MiB。响应头长度和实际流读取均受限。
- 响应 MIME 仅允许 JPEG、PNG、GIF；下载后继续复用阶段 1 的文件签名、实际解码、像素总量和尺寸校验，不信任 URL 后缀。
- 归档 API 复用 `menu.images` 与 `button.images.manage` 服务端权限，并记录请求、成功或失败操作日志。日志不保存图片内容、外链 URL 或存储凭据。

## 依赖与部署影响

- 阶段 0 确认没有安全外链抓取器或任务队列。任务使用现有数据库与 Spring 线程池，没有引入 Redis 队列、消息中间件或新容器。
- 显式声明 OkHttp 4.12.0，以使用可绑定实际连接的自定义 DNS。该 JAR 为 789,531 字节，并且已经由现有 MinIO 8.5.17 传递引入，因此当前制品不会因该声明重复包含一份客户端；显式依赖用于固定编译和维护边界。
- 新增归档超时、大小、重定向、并发、队列和轮询环境变量。部署前必须应用 V23，并继续配置阶段 1 所需的 MinIO bucket 和凭据。
